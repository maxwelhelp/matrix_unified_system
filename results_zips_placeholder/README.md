# Local result ZIPs

Large generated proof archives are not committed to GitHub.

Put local run outputs here or in `runs/`:

- `atlas_full_all.zip`
- `atlas_gen_trace_full_python.zip`
- `controls_v4_results.zip`
- `controls_baselines_top_heads_fixed.zip`
- optional old proof archives

The final report builder expects the main ZIPs under `runs/` by default.
